## Official Resources

- [GoHighLevel](https://www.gohighlevel.com/) — Official website for the all-in-one sales and marketing platform.
- [GoHighLevel API Documentation](https://highlevel.stoplight.io/docs/integrations) — Official API v2 reference documentation with endpoints, schemas, and authentication guides.
- [GoHighLevel/highlevel-api-sdk](https://github.com/GoHighLevel/highlevel-api-sdk) — Official TypeScript/JavaScript SDK with OAuth support, automatic token refresh, and error handling.
- [GoHighLevel/highlevel-api-python](https://github.com/GoHighLevel/highlevel-api-python) — Official Python SDK with webhook support and automatic token management.
- [GoHighLevel/highlevel-api-docs](https://github.com/GoHighLevel/highlevel-api-docs) — Official API v2 documentation repository.
- [GoHighLevel/highlevel-api-php](https://github.com/GoHighLevel/highlevel-api-php) — Official PHP client library for the GoHighLevel API.
- [GoHighLevel/ghl-marketplace-app-template](https://github.com/GoHighLevel/ghl-marketplace-app-template) — Express.js + Vue 3 template for building GHL Marketplace apps with OAuth.
- [GoHighLevel/oauth-demo](https://github.com/GoHighLevel/oauth-demo) — Reference implementation for the GHL OAuth authentication flow.
- [GoHighLevel/ghl-sdk-examples](https://github.com/GoHighLevel/ghl-sdk-examples) — Example apps demonstrating Private Integration Tokens, OAuth 2.0, webhooks, and token storage.
- [GoHighLevel Ideas Board](https://ideas.gohighlevel.com/) — Official feature request and voting platform.
- [GoHighLevel Developer Community](https://community.gohighlevel.com/) — Official community forum for discussions, support, and knowledge sharing.

## SDKs & Libraries

### JavaScript / TypeScript

- [GoHighLevel/highlevel-api-sdk](https://github.com/GoHighLevel/highlevel-api-sdk) — Official TypeScript/JavaScript SDK with built-in OAuth, token management, and comprehensive API coverage.
- [M2KDevelopments/gohighlevel](https://github.com/M2KDevelopments/gohighlevel) — Node.js wrapper library providing a simplified interface for the GHL API.

### Python

- [GoHighLevel/highlevel-api-python](https://github.com/GoHighLevel/highlevel-api-python) — Official Python SDK with webhook support and automatic token management.
- [GearPlug/highlevel-python](https://github.com/GearPlug/highlevel-python) — Third-party Python API wrapper using OAuth2 authentication.
- [M2KDevelopments/gohighlevel-py](https://github.com/M2KDevelopments/gohighlevel-py) — Python ease-of-use library for the GHL API, companion to the Node.js version.
- [MB0390231/highlevel_sdk_python](https://github.com/MB0390231/highlevel_sdk_python) — Python SDK with OAuth flow for HighLevel Marketplace apps.

### PHP

- [GoHighLevel/highlevel-api-php](https://github.com/GoHighLevel/highlevel-api-php) — Official PHP client for interacting with the GoHighLevel API.
- [MusheAbdulHakim/gohighlevel-php-sdk](https://github.com/MusheAbdulHakim/gohighlevel-php-sdk) — Type-safe PHP SDK covering all major GHL API endpoints.

## MCP Servers

Model Context Protocol (MCP) servers enable AI assistants like Claude to interact with GoHighLevel directly.

- [BusyBee3333/Go-High-Level-MCP-2026-Complete](https://github.com/BusyBee3333/Go-High-Level-MCP-2026-Complete) — Most comprehensive GHL MCP server with 520+ tools across 40 categories including Voice AI and Social Media.
- [mastanley13/GoHighLevel-MCP](https://github.com/mastanley13/GoHighLevel-MCP) — Comprehensive MCP server with 269+ tools across 19 categories for Claude Desktop integration.
- [basicmachines-co/open-ghl-mcp](https://github.com/basicmachines-co/open-ghl-mcp) — Open-source MCP server for GHL API v2 with OAuth support.
- [drausal/gohighlevel-mcp](https://github.com/drausal/gohighlevel-mcp) — MCP server for managing contacts, opportunities, calendars, and workflows via AI assistants.
- [robbyDAninja/7fa-ghl-mcp](https://github.com/robbyDAninja/7fa-ghl-mcp) — Efficient MCP server with 34 essential tools optimised for agency management.
- [geopopos/ghl-convo-mcp](https://github.com/geopopos/ghl-convo-mcp) — Specialised MCP server for GHL conversations, tasks, and calendar appointments.
- [CryptoJym/gohighlevel-mcp](https://github.com/CryptoJym/gohighlevel-mcp) — Lightweight MCP server for Claude Desktop with 21 CRM automation tools.
